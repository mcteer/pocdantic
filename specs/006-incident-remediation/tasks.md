## Dependencies and execution order

- T001–T002 establish conventions; T003–T005 are independent foundation test files. T006–T008 establish schemas, T009 builds storage, T010 migration, T011 enrollment and T012 registration.

- T036 can run alongside documentation after all public/private schemas settle; T037–T042 finish the integrated feature. Tests sharing implementation modules follow their corresponding changes sequentially.

## Implementation strategy

The first software checkpoint is setup + foundation + US1 with cleanup disabled. It proves durable local containment, not full incident remediation. Continue through US2 and US3 before claiming the 006 feature complete; checkpoints are verification opportunities, not permission to leave required tasks unfinished. Optional live evidence has its own disposition and is not a reason to halt authorized software work.
